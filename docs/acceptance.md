# 安装与 AI 任务验收

[返回首页](../README.md)

这些是开发测试，不是产品功能。Fairymouse 不内置模型、agent 编排器或测试服务，也不增加模型 SDK 依赖。

## 干净目录安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/clean_install.ps1 -Run
```

脚本将已提交源码导出到 `tests/.work/` 下含中文和空格的新目录，并覆盖当前待验证的安装相关文件；使用空的独立 uv 缓存与 Python 目录进行真实下载。检查缺 Node / uv 的报错、项目内解释器、重复安装、配置绝对路径、两个 MCP 握手与退出。结果见 [clean-install.json](../reports/clean-install.json)。

这是同机隔离目录测试，仍共享 Windows、网络和已有系统组件，不能表述为第二台干净机器验证通过。

## AI 根据观察执行任务

评估者只获得任务目标、输入文件与工具说明，逐步读取控件后自行决定动作。不能把预写应用操作脚本的通过结果当成 AI 自主任务通过。文件工具可准备输入、最终回读，不能直接写出要求由应用生成的成果。

测试任务包括记事本追加并保存、画图旋转并另存、Edge 通过原生另存为保存页面。记录任务完成、未知结果、恢复过程、请求次数与文件证据；本次测试不构成模型能力排名或统计成功率。

本轮 [验收汇总](../reports/acceptance-20261112.json) 区分业务完成与干扰观察：三个应用均完成文件任务与清理；画图 AI 验收及独立的 Edge/画图共存回归通过采样检查。Edge AI 验收有 4 个无效样本，记事本最终 AI 验收有 2 个，其全程无干扰结论仍为不确定，没有用后续通过记录覆盖。

需要独立 MCP 进程与逐步审计时，可在正常登录用户会话运行测试信箱：

```powershell
node tests/interactive_session.mjs tests/.work/my-new-evaluation
```

读取生成的 `tools.json`。每步把 `{ "name": "hidden_...", "arguments": { ... } }` 写到临时文件，再**原子重命名**为 `request-001.json`；等对应的 `response-001.json` 返回后再决定下一步。不要沿用旧目录或重放已执行的请求。无效 JSON 只产生错误响应，不终止会话。

所有应用操作都经过实际 MCP；信箱只负责传递、审计和监测，没有应用流程或模型调用代码。结束前关闭自己的应用并释放桌面，再写 `stop.flag`。原始响应可能包含应用恢复的标签名称等信息，因此只保留在被忽略的 `tests/.work/` 中，对外报告不复制完整窗口树。

## 用户与多个 agent 共存

```powershell
# 用户正常使用电脑时的两路回归；不干预已打开的 WPS
node tests/parallel_apps.mjs --run --paint --without-wps --coexist

# WPS 未运行且具备对应版本时，可加入表格场景
node tests/parallel_apps.mjs --run --paint --coexist
```

默认静止基线监测保持原行为。`--coexist` 使用测试专用监测：登记 PID 与进程创建时间，观察已识别后代、前台、焦点和输入桌面；用户普通鼠标移动、切换窗口不自动算作工具干扰。监测失败、身份不明或采样缺失不能判定无干扰。检测到登记目标进入前台或焦点，停止新的变更；读取与必要清理仍保留。

结果写到 [parallel-coexist.json](../reports/parallel-coexist.json)，与旧的静止基线报告分开。只有应用文件核验、独立桌面、实际重叠请求及各监测器检查都通过，回归才通过。用户活动本身不能仅凭采样归因；采样也无法排除间隔内的瞬时变化。报告保留实际最大采样间隔，不承诺固定 20ms 精度。

## 本轮发现与边界

- 安装器现明确使用项目内 Python，禁止 uv 注册全局入口和 Windows 注册表，正确处理 PowerShell 5 下的中文路径。
- `hidden_create` 返回第一次创建/打开的结果，避免新建桌面被第二次内部查询误报为已存在。
- Edge 临时 profile 仍可能自动同步账号、装扩展、打开欢迎页。临时目录不是账号隔离保证。可重复回归在其专属 profile 使用禁用同步、后台驻留等测试参数；这些参数不改用户原有配置，也不是产品默认策略。
- 关闭浏览器窗口不等于浏览器进程退出。真实 AI 验收通过应用自身“关闭 Microsoft Edge”菜单退出后再释放桌面，没有通过强杀进程冒充正常完成。
- 记事本可能恢复其他标签，只操作目标文档，不能用“全部保存”处理自己的任务。
- 本机已安装的旧版技能不会被安装脚本自动覆盖；使用当前仓库的 [技能说明](../skills/background-desktop/SKILL.md)，迁移旧客户端时同步检查其技能版本。
